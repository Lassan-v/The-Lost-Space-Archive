# The Lost Space Archive — NASA Data Package

Files:
- `NASA_Data_Catalog.xlsx` — workbook with `NASA_Data_Catalog`, `Source_Register`, and `Data_Dictionary` sheets.
- `NASA_Data.json` — structured starter data for the frontend.
- `NASA_Data_Notes.md` — verification guidance, scientific cautions, challenge data-integration plan and handoff checklist.

Important:
- This is a preliminary research scaffold, not an approved final science database.
- Review every source URL and every claim before publishing it in the experience.
- Keep source-specific values when NASA sources disagree.
- The NSSDCA source is identified as a candidate core data source, but meaningful integration is still marked as planned, not completed.
- Preserve the eight separate physical-object records and the five narrative dossier groupings.
