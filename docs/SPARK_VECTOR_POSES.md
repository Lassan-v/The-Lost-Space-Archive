# Spark — Original vector pose inventory

These eight poses are authored as transparent SVG symbols in `public/images/spark-poses.svg`. The same body, wheel pair, projector, face plate, palette, and line weight are reused in every pose. The app selects them through `src/components/content/SparkIllustration.tsx`.

![Eight hand-authored transparent vector poses of Spark, shown in the order listed below](../public/images/spark-poses.svg)

| Order | Pose | Visual action |
|---|---|---|
| 1 | Welcoming | Raises one hand in greeting |
| 2 | Idle | Neutral, friendly expression |
| 3 | Speaking | Open mouth and small sound marks |
| 4 | Explaining | Points toward a discovery |
| 5 | Projecting | Projects a simple hologram from the head unit |
| 6 | Discovering | Looks toward a bright new clue |
| 7 | Surprise | Wide eyes and a surprised mouth |
| 8 | Celebration | Raises both arms with a star accent |

The gallery SVG has a transparent background. Its displayed order is left-to-right across the first row, then left-to-right across the second row. These are original hand-authored vector illustrations, not AI-generated images and not NASA hardware depictions.
