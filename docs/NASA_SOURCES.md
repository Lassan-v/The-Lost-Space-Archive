## Source Priority Hierarchy

Per project rules (CLAUDE.md and nasa-source-of-truth skill):
1. **NSSDCA Master Catalog** — Primary authority for mission records
2. **NASA Science / NASA JPL primary mission pages** — Current mission fact sheets
3. **NASA archives, technical reports, primary publications** — JPL technical reports, mission reports
4. **Other authoritative agencies/academic sources** — Only when primary sources don't cover the claim
