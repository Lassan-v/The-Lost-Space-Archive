# Learning Goals & Progression Map — The Lost Space Archive

**Project:** The Lost Space Archive (NASA Space Apps Challenge 2026)
**Audience:** Children aged 8–10
**Design Principle:** One concept per challenge. Progression from concrete → abstract. Mars → Moon (chronological mission order). Reusable patterns.

---

## Overall Learning Arc

| Stage | Theme | Core Idea | Dossiers |
|-------|-------|-----------|----------|
| 1 | **First Wheels on Mars** | How do we explore another planet? What parts does a rover need? | Sojourner |
| 2 | **Water Detectives** | How do rovers find evidence of past water? Minerals tell the story. | Spirit, Opportunity |
| 3 | **First Flight on Mars** | How does a helicopter fly in 1% Earth air? Cameras watch the ground. | Ingenuity |
| 4 | **Moon Machines: Landers & Rovers** | How did we test Moon soil? How did cars extend human reach? | Surveyor 3, Apollo 15/16/17 LRVs |

---

## Learning Objectives by Dossier (One Per Challenge)

| Dossier | Learning Objective | Bloom Level | Concept Category |
|---------|-------------------|-------------|------------------|
| **Sojourner** | Name 5 key rover parts and their functions (solar panel, cameras, APXS arm, wheels) | Remember / Understand | Hardware systems |
| **Spirit** | Match 3 instruments to the water evidence they discovered (Mini-TES→silica, MB→goethite, APXS→carbonates) | Understand / Apply | Instrument → Discovery |
| **Opportunity** | Identify that the Mössbauer Spectrometer found hematite "blueberries" — proof of liquid water | Understand | Evidence-based reasoning |
| **Ingenuity** | Explain that the downward navigation camera tracks ground features to stay steady in thin air | Understand | Sensor → Stability |
| **Surveyor 3** | Describe how the sampler arm dug trenches to measure soil strength for Apollo landings | Understand / Apply | Experiment → Engineering decision |
| **Apollo 15 LRV** | State that the LRV let astronauts drive 27.8 km and retrieve the ancient Genesis Rock | Remember / Understand | Mobility → Science return |
| **Apollo 16 LRV** | Compare: same rover design, different geology (highlands vs. plains) — breccia, anorthosite, basalt | Analyze | Geological context |
| **Apollo 17 LRV** | Grasp scale: Apollo 17 drove 35.9 km total, 7.6 km from lander — farthest human drive off Earth | Analyze / Evaluate | Magnitude, records |

## Concept Progression (Scaffolded)

```
CONCRETE (Parts you can see)
    │
    ├─ Sojourner: Build the rover → see each part's job
    │
    ├─ Surveyor 3: Operate the arm → see trench depth → learn soil strength
    │
    ├─ Ingenuity: Steer the helicopter → feel "camera watches ground" → stability
    │
    ▼
RELATIONAL (Tool → Discovery)
    │
    ├─ Spirit: Match instrument → mineral → water clue (3 pairs)
    │
    ├─ Opportunity: Choose tool → identify hematite → water proof (1 key link)
    │
    ▼
ABSTRACT (Comparison & Scale)
    │
    ├─ Apollo 15: Drive distance → rock retrieved (Genesis Rock)
    │
    ├─ Apollo 16: Match rock type → site (highlands geology)
    │
    └─ Apollo 17: Place markers on number line → compare 3 missions → grasp record scale
```

## Accessibility & Inclusion Checklist (All Challenges)

- [ ] Single learning objective, stated in child language
- [ ] Instructions ≤ 2 short sentences
- [ ] Technical terms defined inline
- [ ] Keyboard + touch + switch operable
- [ ] Screen reader labels on all interactive elements
- [ ] Live region for feedback (polite)
- [ ] Reduced motion: instant transitions, no auto-play animation
- [ ] High contrast: 7:1 text, 4.5:1 UI, 3px focus rings
- [ ] Touch targets ≥ 44×44 px (56×56 preferred)
- [ ] No time pressure, no failure penalties, unlimited retries
- [ ] Persistent "Memory Station" return button (top-left, accessible)
- [ ] Simulation banner visible: "Simulation — simplified for learning. Real mission data from NASA sources."

- **Vocabulary Journal:** Collected terms with audio definitions
